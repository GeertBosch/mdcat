Mermaid label text
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

On a Kitty terminal, the built-in renderer writes every label as ordinary text
over the diagram's image, so the text keeps the terminal's font and colours.
This fixture covers what a label may hold: quoted text, entity codes, line
breaks, and Markdown strings. A node with a label of n lines is n + 2 rows tall,
and its outline follows it. Each line is centred in the box. Checked by
mermaid-kitty.sh at width 80, with --img kitty and pinned cell sizes: the
.w80.txt golden holds the previewed text and quadrant blocks, the .w80.ansi.txt
golden the text layer with its styles (\e is ESC), and the .err golden names the
diagrams that are declined and so shown as source.

Quoted labels
────────────────────────────────────────────────────────────────────────────────

Expected: the quotes are not shown, and the brackets, parentheses and pipe
inside them are literal text instead of syntax. A quoted label on an edge is
drawn on it, in both spellings (-- "text" --> and -->|"text"|), and a --> inside
the quotes does not end the link. The first node's label is 36 columns wide, so
it wraps after a space at 24, as every plain label with spaces does.

Entity codes
────────────────────────────────────────────────────────────────────────────────

an ampersand. A hash sign that does not start an entity code stays as it is.

A literal less-than sign
────────────────────────────────────────────────────────────────────────────────

Expected: a < is a tag only when a letter, / or ! follows it; otherwise it is
text, as > is. So c < 5, b >= 0 and 1 <= 2 are drawn as written, in a quoted
node label, an unquoted one, a Markdown string, a quoted edge label and the text
in the middle of a link. <br> still breaks a line.

Markdown strings
────────────────────────────────────────────────────────────────────────────────

Expected: **bold**, *italic* and  `code`  are styled in the text layer, and the
markers are not shown. A newline inside the string is a hard break. An entity
code becomes its character and is never read as Markdown: #42; is a literal
star.

Declined
────────────────────────────────────────────────────────────────────────────────

Expected: shown as source, as the .err golden says, in this order. HTML other
than a line break; an entity code that is not known; a quote that never closes;
a Markdown string with HTML in it; a label with a quote inside the quotes; a<b,
where <b starts a tag.

  graph TD
      a["<b>bold</b>"] --> b[B]

  graph TD
      a["#nosuchentity;"] --> b[B]

  graph TD
      a["unclosed] --> b[B]

  graph TD
      a["`<i>x</i>`"] --> b[B]

  graph TD
      a["say "hi""] --> b[B]

  graph TD
      a["a<b"] --> b[B]
